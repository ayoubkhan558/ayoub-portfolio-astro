# Muhammad Ayoub — Astro Portfolio v1.3.0

**Lightweight source-only update.** This ZIP deliberately does **not** include `public/`, `dist/`, `node_modules/`, or preview screenshots. Your original portfolio JSON and its structure are unchanged.

## Apply this cleaned update

This is a clean source bundle, **not an overlay**: merging it over the old `src/` would leave deleted template files behind.

1. Back up your previous project, then extract this ZIP into a **new, empty folder**.
2. Copy only the existing `public/` folder from your previous Astro portfolio into the new project root. It contains all unchanged images, fonts, logos, screenshots, favicon and Resume. If applicable, copy your `.env` too.
3. Do **not** copy the old `src/`, `package.json`, lockfile, `node_modules/`, or `dist/`.
4. Use Node.js **22.22+** (Node 24 recommended), then run:

```sh
npm ci
npm run check:integrity
npm run dev
```

Without the previous `public/` folder, fonts/images/downloads will be missing. Do not use Next.js build commands. `dist/` is regenerated by `npm run build`.

## Build & deploy

```sh
npm run check
npm run build
npm run preview
```

Astro generates `dist/` locally. Deploy its contents to static hosting. Netlify, Cloudflare Pages and Vercel: build command `npm run build`, output directory `dist`. Use the Astro/static preset, not Next.js. Host at the domain root; configure `404.html` as your error page and support directory-style routes such as `/about/`.

Do not double-click generated HTML: use a web server. No server adapter, database or new mail backend is required.

## Package updates

All 29 direct packages were checked against the npm registry and updated to their latest stable versions **except TypeScript**, which is on the latest compatible **6.0.3**. The current Astro checker supports TypeScript 5/6 and the TypeScript ESLint parser requires a version below 6.1; TypeScript 7 is not yet in their supported peer ranges. No forced/legacy peer resolution is used.

Key versions: Astro 7.4.1, React/React DOM 19.3.1, Tailwind CSS 4.3.3, Lucide 1.59.0, ESLint 10.13.0 and Prettier 3.9.10. The old ESLint import plugin was replaced with its maintained ESLint-10-compatible successor, `eslint-plugin-import-x`. Exact old/new versions and the compatibility exception are in `qa/dependency-versions.json`.

For repeatable browser tests, run `npm run preview` in one terminal. In another:

```sh
npx playwright install chromium

npm run test:interactions
npm run test:extra
npm run test:design
```

Alternatively set `CHROMIUM_PATH` to an installed Chromium executable. `QA_BASE_URL` defaults to `http://127.0.0.1:4321`; `QA_OUTPUT` defaults to `qa-results`. Run only against a local/test site; contact requests are mocked, never sent. Automated axe checks are not a complete accessibility certification.

`npm run format` deliberately excludes dynamic Astro templates and `src/data/` to preserve their exact structure. The formatter packages are current; dynamic templates remain an explicit opt-in. Astro's compiler/type checker and built-content guards validate those templates. `npm run lint` is non-mutating; `npm run lint:fix` is explicit.
